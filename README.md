# The joke the reviewer laughs at

An entry for the make.fun bounty [The joke the reviewer laughs at](https://make.fun/bounty/the-joke-the-reviewer-laughs-at-20261121-0329).

`main.py` (Python 3.13, standard library only, no network) writes one
text to `/output/entry.txt`: an original one-line joke about working
beside an AI coding agent — the moment every reviewer of an agent's
change recognises at once.

Run it twice and the output is byte-identical both times.
